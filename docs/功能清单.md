## 已实现能力汇总（MVP 骨架）

| 模块 | 文件 | 说明 |
|------|------|------|
| HTTP 发送 | `services/http_service.go` | method/url/query/headers/body、超时、跳过 TLS；缺 URL 规范化、编码、重定向策略 |
| WebSocket | `services/ws_service.go` | 多连接管理、事件推送收发消息、主动断开 |
| 本地存储 | `services/storage_service.go` | collections/environments/history 的 JSON 读写、原子写入；**前端未接入** |
| 前端外壳 | `frontend/src/App.vue` | HTTP/WS 模式切换、单页布局 |
| 请求面板 | `frontend/src/components/RequestPanel.vue` | URL 栏 + Query/Headers/Body 标签 |
| 响应面板 | `frontend/src/components/ResponsePanel.vue` | 状态/耗时/大小 + Body/Headers 标签 |
| WS 面板 | `frontend/src/components/WSPanel.vue` | 连接 + 日志 + 发送 |
| 键值编辑器 | `frontend/src/components/KvEditor.vue` | 启用/key/value/删除 |
