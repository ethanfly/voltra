# Voltra 界面原型说明 v0.2

配套可交互原型：**`docs/prototype/index.html`** —— 用浏览器直接打开即可。右下角有"原型演示"控制条，可切换明暗主题、正常/错误响应、空状态、分栏方向、生成代码抽屉。
实施总纲见 [`交接说明.md`](交接说明.md)。

原型为**中保真线框**。**作为实现基准的部分**（必须对齐）：六区布局与划分、区域尺寸（活动栏 48px、侧栏 240–480px 可拖拽、行高 28/36px）、控件形态与层级、§3 的设计令牌（配色/字体/圆角/方法色）、明暗双主题。**仅作示意的部分**（可自由调整）：具体文案、示例数据、图标细节、动画、`prototype/index.html` 里的类名与 DOM 结构（不要求照抄）、右下角"原型演示"控制条（正式产品无此条）。

## 2. 关键控件设计

### 接口树（③ 集合面板）
- 层级：`集合 ▸ 文件夹（可嵌套）▸ 接口`，展开箭头 + 类型图标。
- 每个接口左侧 **方法色标**：GET 绿 / POST 橙 / PUT 蓝 / PATCH 紫 / DELETE 红 / WS 青。
- 集合/文件夹右侧显示子项数量。
- 顶部：`新建` 按钮 + `导入` 图标；下方 `搜索框`（按名/URL/方法过滤）。
- 交互：单击选中并在当前标签打开、双击在新标签打开、右键菜单、拖拽排序、F2 重命名。

### URL 栏（⑤）
- 方法选择器：带方法色，等宽字体。
- URL 输入：`{{变量}}` 高亮为品牌色胶囊；无 `://` 时灰显补全提示（如 `https://` 前缀预览）。
- 按钮：`</>` 生成代码（图标按钮）+ `保存`（幽灵按钮，Ctrl/Cmd+S）+ `发送`（主色实心，请求中变"取消"）。

### 请求子标签
| 标签 | 内容 |
|------|------|
| Params | 键值表：启用勾选 / 参数名 / 参数值 / 说明 / 删除；与 URL 双向同步；禁用行置灰划线 |
| Body | 段控件 `none / form-data / x-www-form / raw / binary / GraphQL`；raw 再选 `JSON/XML/Text`；代码区假高亮 + `格式化` `校验` |
| Headers | 键值表；**继承/自动 Header** 用置灰斜体行展示（如集合级 `Authorization`、自动 `Content-Type`），可覆盖 |
| Auth | 类型下拉 `None/Bearer/Basic/API Key/继承`，对应字段；提示变量将按当前环境替换 |
| Scripts | 段控件 `前置脚本 / 后置断言`；代码区；注明"运行引擎 v0.3，当前仅保存" |
| Settings | 超时、跟随重定向+最大次数、跳过 TLS 校验、发送 Cookie |

### 响应区（⑥）
- 状态行：状态码胶囊（2xx 绿 / 4xx·5xx 红）、耗时、大小、时间戳、`另存为示例`。
- Body 工具条：`Pretty/Raw/Preview` + 复制 / 下载 / 换行 / 折叠全部 / `JSONPath·关键字` 搜索框。
- Body：按 Content-Type 语法高亮（key 紫 / string 绿 / number 橙 / bool·null 蓝）。
- Cookies：表格解析 Set-Cookie。Headers：响应头。Tests：断言结果（✓/✗）。Timeline：DNS/TCP/TLS/TTFB/下载 耗时拆解。
- **错误态**：整块替换为居中卡片——图标 + 标题（如"URL 缺少协议前缀"）+ 说明 + 可能原因 + `补全并重试` / `编辑 URL` 按钮。

### WebSocket 视图（④ 选中 WS 类型接口时）
- URL 栏方法位显示 `WS`，按钮为 `连接`（青色）；`握手 Headers` 入口。
- 时间线气泡：`收到`(左，浅底) / `发送`(右，品牌色) / `系统`(居中，灰字)；JSON 自动格式化。
- 底部发送区：`Text/JSON/Binary` 段控件 + 输入框 + 发送。

### 生成代码面板（点 URL 栏 `</>` 打开）
- 右侧抽屉弹层。左列：语言分组树（Shell / Python / JavaScript / Node.js / Java / PHP / Go / C# / Ruby / Swift / Kotlin …），每语言下可选客户端库（如 Java → OkHttp / java.net.http / Unirest）。
- 右区：实时生成的代码，语法高亮；顶部 `复制` `在编辑器打开`，开关"用当前环境真实值替换 `{{变量}}`"。
- 底部提示：生成的代码与实际发出的请求等价（method / URL / query / header / body / auth 一致）。
- 原型演示：右下角"原型演示"条 `生成代码` 按钮打开此弹层。

### 空状态（无项目）
主区居中三张大按钮卡片：`新建项目` / `导入 Postman` / `从 cURL 创建`。

## 3. 设计体系（令牌）

| 项 | 明亮 | 暗色 |
|----|------|------|
| 背景 / 卡片 | `#f4f4f6` / `#ffffff` | `#17181c` / `#1e1f24` |
| 边框 | `#e2e2e6` | `#2c2d34` |
| 主文字 / 次要 / 弱 | `#1f2024` / `#6b6b74` / `#9a9aa2` | `#e7e7ea` / `#9a9ba4` / `#6a6b74` |
| 品牌色 | `#5b4ee0` | `#8b7dff` |
| 圆角 | 6px（控件）/ 4px（小元素） |
| 字体 | 系统 UI 字体；代码/URL/键值用等宽 |
| 方法色 | GET `#3aa856` · POST `#d98613` · PUT `#2f7ed8` · PATCH `#8a5cf6` · DELETE `#d64545` · WS `#12a5a5` |

- 三主题：明 / 暗 / 跟随系统；切换即时，全界面无残留色块。
- 密度：行高 28px（树）/ 36px（标签、控件），贴近 Apifox/Postman 的信息密度。

## 4. 与当前 MVP 的差异一览

| 维度 | 当前 MVP | 原型 v0.2 |
|------|---------|-----------|
| 导航 | 顶部两个按钮切 HTTP/WS | 活动栏 + 侧边栏 + 多标签页 |
| 接口组织 | 无，只有一次性请求 | 项目/集合/文件夹/接口 树 + 持久化 |
| 主题 | 仅浅色硬编码 | 明/暗/跟随系统 + 设计令牌 |
| 请求能力 | Query/Headers/Body(4类) | +Auth、+form-data/binary/GraphQL、+Settings、+Scripts、变量高亮 |
| 响应能力 | Body/Headers 两个 pre | +Pretty/Raw/Preview、Cookies、Tests、Timeline、工具条、错误卡片 |
| 环境变量 | 无 | 环境下拉 + `{{变量}}` 替换 + 管理面板 |
| 历史 | 后端有存储、前端无 UI | 侧边栏历史列表 + 一键还原 |
| 导入导出 | 无 | Postman v2.1 / cURL / 自有 JSON |
| 生成代码 | 无 | 一键转 cURL/Python/JS/Node/Java/PHP/Go/C#/Ruby/Swift/Kotlin… 客户端代码 |
| 发送 bug | `www.baidu.com` 报错 | URL 规范化 + 友好错误 + 一键补全重试 |

6. 环境与变量
7. 历史打通
8. WebSocket 视图并入树
