## 7. 已知限制与技术债

- **Wails beta 版本错位**：Go 侧 beta.3 + npm 锁定 `@wailsio/runtime@3.0.0-beta.16`（beta.3 在 npm 不存在，`^3.0.0-beta.3` 实际解析到 beta.16）。实测组合可用并已精确 pin；协议异常时需两侧同升。
- **构建目标**：本机 Go 环境固定 `GOARCH=amd64`，产物在 arm64 Mac 上走 Rosetta 运行（已验证）；原生 arm64 发布需改 Go 环境重构建。
- **beforeunload 落盘**：桌面窗口关闭触发 `beforeunload` 异步 flush，极端情况下最后 500ms 内的编辑可能丢失（常规编辑有防抖即时落盘兜底）。
- **树搜索**：按名称、非虚拟滚动的平铺命中列表（1000 节点验证无压力；万级节点时需 windowing，预留点已记录）。
- **大响应**：Go 侧 64MB 截断（truncated 标记）；前端 >1MB 不自动 Pretty、>10MB 禁用 Pretty/JSONPath。
- **交接文档失真**：`docs/交接说明.md` 的"已完成"描述与事实不符，其"剩余工作"章节可作为 v0.3 参考但需按本报告核对。
